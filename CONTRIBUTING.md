# PC Game Performance & Hardware Analyzer (Claude Skill)

A Claude skill that checks whether a PC or laptop can run a game, finds the
bottleneck, and gives a tailored plan for better FPS and better graphics.

## What you get

- Current minimum and recommended requirements (looked up on the web each time)
- Your hardware compared with the requirements, with the main bottleneck named
- **Rating system out of 10:** PC Spec Rating and Game Performance Rating, plus per-component scores
- Exact in-game settings, ranked by FPS impact
- Upscaling and frame generation setup (DLSS, FSR, XeSS) for your GPU
- Predicted FPS table for 1080p, 1440p and 4K (labeled as estimates with a confidence level)
- Extra tips: drivers, Windows, laptop cooling, upgrade advice
- A colorful HTML dashboard report with gauges, score bars and a Quick Setup summary

  Web search must be available in your Claude plan for best results.
